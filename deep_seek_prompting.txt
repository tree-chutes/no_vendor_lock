Ask me one question at a time so we can develop a java class that extends the attached class.

Use the package deepseek.demo for all your work. Use apache pdfbox

Define a public enum in its own file, call it DocumentStage with the following labels: 

LOAD_PDF, ADD_PAGE, REMOVE_PAGE, SAVE_PDF. No more is required of DocumentStage

The extended class will be called DocumentWorkUnit. Use DocumentStage to extend  DocumentWorkUnit.  
Add only the following fields to DocumentWorkUnit: one that holds an pdf document call it myPdf. 
These fields are public and do not need accessors methods.

DocumentWorkUnit constructor should take an extra parameter: map of strings. This map contains a key called “stages”. 
Its value contains the labels of DocumentStage separated by commas. Use these labels to feed the field called “stages” in the base class. 
Verify the key exists and that each label is valid for DocumentStage

Create a processing class, call it DocumentProcessor with 4 methods (each method takes and returns the same instance of  DocumentWorkUnit) 
This class does not need to check the stages

The first method called “loadPdf” uses the payload field from the base class to load the pdf document into field called myPdf. 
If the payload is null, store “null payload” as bytes in the payload field, set the field done to true and status to the html status code “unprocessable entity”. 
If the payload can not be loaded add “invalid payload” as bytes to the payload field, set the done field to true and status to o the html status code “unprocessable entity”


The second method called “addPage” uses myPdf field and adds a page to the pdf. It also adds a line of text in Helvetica font, size 12. The content of the line is the DemoWorkUnit field _PrintMe. If myPdf is null, store “null workbook” as bytes in the payload field, set the field done to true and status to the html status code “unprocessable entity”. 
If the text can not be added add  “invalid pdf” as bytes to the payload field, set the done field to true and status to o the html status code “unprocessable entity”

The third method called “removePage” uses myPdf field and remove the first page of the document

The fourth method called savePdf will do the following: if myPdf is not null will save the pdf in the  payload field. Then set the done field to true and set the status field to http status success. If myPdf can’t be saved add “pdf can not be saved” to the payload field, set the done field to true and status to o the html status code “unprocessable entity”

use gradle to build the jar library. Include all dependencies required in the library
